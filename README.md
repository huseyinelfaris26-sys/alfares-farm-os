# ALFARES FARM OS AI 🌾

| الخدمة | المنفذ | الوظيفة |
|---|---|---|
| farmOS | 8080 | إدارة الحقول والمحاصيل والسجلات + خرائط |
| weather | 8001 | الطقس والتوقعات ونصيحة الري (Open-Meteo مجاني) |
| disease | 8002 | تشخيص أمراض النبات من صورة الورقة + العلاج (نموذج PlantVillage) |
| fertilizer | 8003 | كمية البذور والأسمدة للدونم (العراقي 2500 م²) حسب تحليل التربة |
| ndvi | 8004 | مراقبة صحة المحصول من القمر الصناعي Sentinel-2 (مؤشر NDVI) |
